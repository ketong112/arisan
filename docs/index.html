🪙 Arisan

Rotating savings circle, fully on-chain. Every member contributes every round; every round one member — in join order — takes the whole pot. No bank, no middleman, no trust needed beyond the code.

What is arisan?

Arisan is an Indonesian tradition older than any bank: a group of neighbours, coworkers or family each put in a fixed amount every week or month, and each round one member takes the entire pot. It is savings, credit and community in one ritual — and it runs on trust.

This realm moves that trust on-chain. The rules (who joins, who paid, whose turn it is, where the money goes) and the money itself live in a Gno smart contract. Nobody — not even the organizer — can take the pot out of turn, skip a payment unnoticed, or change the rotation.

How it works

  1. Create a circle — anyone can create one: a name, a contribution per round (ugnot), a maximum number of members. The creator becomes the organizer.
  2. Join — members join while the circle is open. Join order is rotation order: first to join, first to take the pot. Deterministic, no lottery, no randomness.
  3. Start — the organizer starts round 1 once at least 2 members have joined.
  4. Deposit — every round, each member pays exactly the contribution with -send. Unpaid members are flagged BELUM BAYAR on the dashboard for everyone to see.
  5. Advance — the organizer advances the round only when every member has paid. The pot (members × contribution) is paid from the realm to the member whose turn it is, and the next round begins. The rotation wraps around, so everyone eventually takes the pot.

Try it (Onyx testnet)

Install the Gno toolchain, fund a key at faucet.gno.land (Onyx), then run:

REALM="gno.land/r/g1u9frcg00ncx6ws8h6whtkdg2z4gsv0hjvzh20w/arisan"
RPC="https://rpc.onyx.testnets.gno.land:443"

# 1. Create a circle (name, contribution in ugnot, max members)
gnokey maketx call -pkgpath "$REALM" -func CreateCircle \
  -args "Arisan RT 05" -args 1000 -args 4 \
  -gas-fee 20000ugnot -gas-wanted 10000000 \
  -chainid onyx-1 -remote $RPC mykey

# 2. Join circle #1
gnokey maketx call -pkgpath "$REALM" -func JoinCircle -args 1 \
  -gas-fee 20000ugnot -gas-wanted 10000000 \
  -chainid onyx-1 -remote $RPC mykey

# 3. Organizer starts round 1
gnokey maketx call -pkgpath "$REALM" -func StartCircle -args 1 \
  -gas-fee 20000ugnot -gas-wanted 10000000 \
  -chainid onyx-1 -remote $RPC mykey

# 4. Deposit your contribution for the round
gnokey maketx call -pkgpath "$REALM" -func Deposit -args 1 \
  -send 1000ugnot -gas-fee 20000ugnot -gas-wanted 10000000 \
  -chainid onyx-1 -remote $RPC mykey

# 5. Organizer advances when everyone has paid
gnokey maketx call -pkgpath "$REALM" -func AdvanceRound -args 1 \
  -gas-fee 20000ugnot -gas-wanted 10000000 \
  -chainid onyx-1 -remote $RPC mykey

Read the state any time: gnokey query vm/qeval -remote $RPC -data "$REALM.Render("/1")"
